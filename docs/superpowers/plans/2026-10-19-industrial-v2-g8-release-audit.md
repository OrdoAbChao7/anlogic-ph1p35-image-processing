# G8 发布审计执行计划

## 目标

把 G8 的正式发布条件转成可复跑的审计，保留当前真实阻塞项，并为未来的 TD/上板/发布包证据提供固定入口。

## 任务

- [x] 先写 G8 审计模型测试：全 PASS 才 RELEASED，任一硬件门阻塞都不能被视觉批准覆盖。
- [x] 实现 `scripts/verify_industrial_v2_release.py`，绑定 V1 SHA、V2 阶段状态、发布目录和十二项退出门。
- [x] 使用 `--strict` 执行审计，记录当前 `BLOCKED` 结果和所有阻塞原因。
- [ ] 只有在正式顶层、TD、Bitstream、板卡和外部执行机构证据到齐后，重新运行并冻结发布包。

## 退出条件

当前阶段退出条件是：审计脚本可从工作树运行、V1 SHA 复核通过、十二项退出门均被逐项列出，且阻塞状态不被误报成 `RELEASED`。G8 正式发布退出条件仍服从项目 G8_EXIT，不能由本次审计脚本提前满足。
