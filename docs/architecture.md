# FPGA 双路线开发体系战略与架构总览

## 1. 战略背景与双轨路线设计

面向 2026 全国大学生嵌入式芯片与系统设计竞赛（安路赛题二），硬件平台为 **安路 HX1P35A (PH1P35MDG324)**，摄像头为 **SC520CS (RAW10 MIPI CSI-2)**，视频目标为 **1280×720@30fps HDMI**。

为了确保大赛交付的确定性与技术天花板的突破，项目确立**双路线独立开发体系**：

```

                    │  底座视频硬件流 (Goal 1 基线 / 已实测闭环)     │

                    └──────────────────────┬───────────────────────┘
                                           │
                 ┌─────────────────────────┴─────────────────────────┐
                 ▼                                                   ▼
┌─────────────────────────────────┐                 ┌─────────────────────────────────┐
```

## 2. Git 物理隔离与协作准则

1. **唯一事实源**：本地 Git 仓库为唯一事实源，严格记录每个稳定阶段的 Commit ID 与报告哈希。
2. **Worktree 物理目录隔离**：
   - 主工作区（`main`）：`E:/Projects/FPGA`
   - 备用工作区（`fallback/industrial-inspection`）：`E:/Projects/FPGA-fallback`
   - 两个目录具有各自独立的文件锁、构建缓存与仿真工作区，互不干扰。
3. **公共底层同步纪律**：
   - 共享的视频采集（MIPI PHY、I2C 配置、ISP 去马赛克、白平衡）、DDR2 读写控制器、HDMI 显示逻辑若有底层修复，必须先在主工作区形成独立、干净的 Commit，再通过 `git cherry-pick` 同步到备用分支。禁止直接跨目录无审查覆盖！

## 3. 主线（YOLO 智能视觉）架构规范

- **显示流**：SC520CS -> MIPI -> ISP -> 卡通化（Line Buffer + 亮度量化 + Sobel轮廓融合） -> DDR2 -> HDMI。
- **检测流**：DDR2 / 视频分叉流 -> ROI提取与尺寸缩放（64×64 / 96×96） -> 片上权重流式计算加速器（INT8 MAC阵列） -> 候选框与置信度解析 -> NMS -> OSD 坐标叠加 + LED/蜂鸣器/WM8978 联动。

## 4. 备选线（传统工业检测）架构规范

- **检测链路**：SC520CS -> MIPI -> ISP -> 灰度变换与滤波 -> 动态/自适应阈值分割 -> 形态学开闭运算（去毛刺与填孔） -> 连通域/目标包围盒统计（BBox, Area, Centroid） -> 尺寸测量（像素换算）与缺角/裂纹缺陷判定 -> OSD 框选/数据标注 -> HDMI 工业人机界面。
- **独立工程入口**：在备用工作区中维护独立 TD 编译工程，确保一键生成 Bitstream。
