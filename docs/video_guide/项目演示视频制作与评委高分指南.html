一、 评委心智模型与终极评审逻辑（知己知彼）
🎯 评委的真实心理与工作常态
  • 评委熟悉赛道，不听原理科普：评委全是资深专家，不需要逐字念算法底层公式或代码定义，只看“算法是否真实生效、提升幅度有多大”。
  • 超负荷连续看片，视觉极度疲劳：连续数小时审阅数十个视频，抖动、无意义长片头、逐字乱蹦字幕等小毛病在后期会被无限放大，严重拉低印象分。
  • 不比算法数量，比实效与攻坚力：同赛道算法名称高度雷同（Sobel、白平衡、边缘检测），只堆砌算法名只能拿基础及格分；能解决极端场景才有高分。

二、 致命雷区与避坑方案（最需要优先规避的扣分大忌）
⚠️ 头号致命死穴：算法演示“看不到前后画面差异”（毫无说服力）
现场惨剧：队员嘴上滔滔不绝讲解算法有多复杂，画面中点下开/关按键，屏幕上图像肉眼看不出任何明显变化。评委无法验证功能是否真的在板卡上跑通，就算自称做了十几种高深算法，也会直接判定为“不可信 / 未真实接入”。
✅ 满分破解法：
  1. 精心策划“放大镜场景”：必须挑选能够极端放大算法价值的素材（例如：针对降噪选暗光噪点图、针对Sobel选轮廓模糊弱边缘图、针对白平衡选严重偏暖偏蓝图）。
  2. 铁律演示逻辑：固定相机机位 → 展示不加算法的劣质原图 → 切换开启算法 → 直观展现局部细节跃升。
⚠️ 二号致命死穴：通篇“报菜名”，脱离实际痛点场景（沦为平庸流水账）
现场惨剧：机械式罗列“我做了边缘检测、我做了伽马变换、我做了颜色量化”，把工程做成了课本实验汇报，没有交代“到底在什么苛刻环境下解决了什么行业难题”。

一、 3分钟标准时间分配甘特条（每一秒都为给分点服务）
① 开头引入 (前40秒)
5s抓眼球 · 40s交代系统概况
② 中间主体：核心功能深度演示 (110秒)
同屏对比 · 逐步叠加 · 极端工况实测 · 软硬联动
③ 结尾总结 (30秒)
全功能综合呈现 · 客观价值
0:00 (起跑即冲刺) 0:05 (片头极限) 0:40 (完成立项交代) 2:30 (核心功能演示收官) 3:00 (稳步收尾)
1️⃣ 开头引入：极速立意 (0~40s)
  • 片头严禁超过5秒：动态项目Logo+一句话系统主题，立即切入实物镜头。绝不可放十几秒炫酷但无内容的模板片头！
  • 40秒内讲透全貌：交代硬件平台、核心输入输出（如SC520CS RAW10 → FPGA → HDMI 720p）、系统解决的痛点及技术难度。
  • 先声夺人，不纠结细节：让评委瞬间清楚“你在做什么、指标有多硬核”，底层寄存器和代码放后续。
2️⃣ 中间主体：核心演示 (40s~2m30s)
  • 直观对比是一切的前提：关闭算法 vs 开启算法，必须同屏或同一场景前后切换，展示肉眼可见的质变。
  • 高分秘籍：逐步叠加演进：从最恶劣原图开始 → 开ISP → 画面纯净 → 开Sobel → 轮廓显现 → 开检测 → 框准计数。一步步展现FPGA各流水级贡献！
  • 肉眼难见则“波形/声光可视化”：若效果是延迟小或功耗低，用示波器波形、LED联动、音频输出等具象化展示。
  • 主次分明，大胆断舍离：重点突出复杂算法与核心指标；简单点灯按键一带而过，不占用宝贵时长。
3️⃣ 结尾总结：全貌收束 (2m30s~3m)
  • 全功能复合运行：原图预处理 + 算法增强 + OSD叠加 + 目标检测 + 声光告警全链路满载运行，展示系统综合稳定性。
  • 量化指标总结：客观列出吞吐率、帧率（30fps/60fps）、端到端延迟（<2ms）、资源占用率与时序收敛情况。
  • 客观求实，不夸大吹嘘：说明在工农业、工业分拣等真实场景中的落地潜能，不使用违背工程常识的过火词汇。
二、 标杆案例评析：从实战经验中汲取高分技巧
📺 案例一：分区背光演示视频深度复盘 典型示范
👍 值得学习的 4 大优点：
  • 直观对比演示：同屏并排放置“原始画面 vs 分区背光画面”，重点凸显黑场深邃度，差异一目了然。
  • 同场景统筹展示：对照实验置于同一视频帧内，观看者无需脑补即可横向比对细节。
  • 适度倍速处理：加快平淡讲解过程，极大提升有限时长内的信息密度。
  • 顶部/底部进度条：标明视频所处阶段，方便评委快速跳转与定位关注点。
❌ 暴露的缺陷与整改对策：
  • 转场过于花哨：技术视频应质朴简洁，过度炫技转场极易分散评委对画面算法的注意。
  • 进度条配色失误：黑底配暗蓝字，未播放文字无法辨识。整改：提高对比度与鲜艳度，重点文字高亮。
  • 倍速失控：个别段落倍速过快导致听不清。整改：语速倍速绝对不可超过1.5倍。
  • 缺少序号标注：各阶段边界模糊。整改：加上“模块 1 / 模块 2”等明确层级编号。
🌟 案例二：特等奖级演示视频的高分套路 高分范例
🏆 优秀作品的 4 个关键做派：
  • 模块化分层讲解（基础分 + 加分亮点）：
    明确划分为“基础功能模块（保证题目基础分全拿）”与“特色拓展创新（YOLO智能检测/声光联动，冲刺一等奖）”，让评委按图索骥精准给分。
  • 逐步叠加递进（像剥洋葱一样展现技术）：
    初始故意展示较差/有瑕疵的恶劣工况画面 → 开启白平衡（色彩恢复）→ 开启Sobel（边缘凸显）→ 开启检测（框线紧锁）。评委能亲眼见证每一行RTL代码的价值！
  • 手术刀级精炼旁白（字字珠玑，零废话）：
    每一句台词都在解释屏幕上正在发生的变化，坚决摒弃“众所周知”、“接下来我将为大家介绍”等无意义水词。
  • 高亮箭头与动态ROI画中画辅助：
    在屏幕对比区域使用简洁清晰的高对比度箭头或微光圈，把评委视线直接引向算法生效的核心像素群。

一、 拍摄现场环境与画面构图原则
🏢 拍摄现场环境“三严禁与三必须”
  • 场景严禁出现杂物：桌面严禁出现吃剩的外卖饭盒、零食袋、饮料瓶、散乱草稿纸或与实验无关的杂物。环境必须朴素、干净、整洁！
  • 严禁暴露违规与敏感隐私信息：背景黑板、电脑桌面、海报上绝不能出现涉密信息、无关不安全内容；严格规避指导教师姓名等违规身份信息。
  • 光线必须充足均匀：选择采光良好、无频闪日光灯的实验室。相机测光锁定，避免屏幕翻拍时因自动曝光造成忽明忽暗。
🖼️ 同屏对比与画中画使用技巧
  • 主次绝不能颠倒：画面的核心视觉重心必须是处理前与处理后的图像对比区域。文字标注只能充当点睛辅助，严禁大块文字遮挡核心显示区。
  • 画中画（PIP）与局部放大：既要保留整幅视频全局画面，又要开辟画中画放大关键细节（ROI），展现微观像素质量提升。
  • 转场与特效质朴极简：杜绝旋转、三维翻转等花哨特效；使用硬切或0.2秒极短淡入淡出，保持专业学术质感。
二、 次要扣分点速查（容易被忽视、但会累积恶感的小毛病）
🛑 4 大隐蔽扣分细节
  • 镜头抖动、频繁对焦变焦：手持手机拍摄晃动剧烈，让疲惫的评委产生生理眩晕感。对策：必须上三脚架或桌面固定支架。
  • 字幕文字“逐字打字机蹦出”：分散视线。对策：字幕以完整语义短句整行一次性呈现，方便一秒扫完。
  • 堆砌大段专业原理小论文：屏幕放满公式定义。对策：精简提炼为核心参数与性能指标（如 FPS、Latency、Loss）。
  • 冗长无聊的操作过程占满画面：如慢吞吞敲上位机指令、慢慢拧旋钮。对策：这类非核心操作直接切片或4倍速一带而过。
💡 演示素材选择的精明心机

选错素材 = 满盘皆输！如果拿光照极好、无任何缺陷的完美图片来演示图像增强，再顶级的算法开启后也没有视觉变化！

针对性素材搭配指南：
降噪 / 滤波算法选用暗光高噪点画面，开启后背景瞬间纯净平滑。
Sobel 边缘检测选用灰度对比弱、轮廓复杂的工件，开启后边缘如刀刻般分明。
自动白平衡 (AWB)选用强偏黄/偏蓝色温场景，开启后恢复标准中性灰。
YOLO-tiny 目标检测选用多目标密集排布、轻微遮挡、运动工件，体现高抗扰与稳定追踪。
