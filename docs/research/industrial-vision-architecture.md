**目标硬件**：安路科技 HX1P35A 开发板 (`PH1P35MDG324`)
**视频输入**：SC520CS RAW10 MIPI D-PHY / CSI-2 (1280×720@30fps)

## 1. 系统总体架构与数据流

工业视觉检测系统作为独立视觉处理通路，保留已验证的官方 MIPI 采集、ISP 拜耳解码、DDR2 帧缓存与 HDMI 显示时序基线，在 DDR2 读出与 HDMI 混合层之间以分层架构接入：

```text
       +-------------------------------------------------------------+
       |                     SC520CS (RAW10 MIPI)                    |
       +-------------------------------------------------------------+
                                      |
                                      v
       +-------------------------------------------------------------+
       |                MIPI D-PHY / CSI-2 解包 IP                   |
       +-------------------------------------------------------------+
                                      |
                                      v
       +-------------------------------------------------------------+
       |               ISP 预处理 (拜耳解码 Demosaic / AWB)            |
       +-------------------------------------------------------------+
                                      | 96-bit (4 pixels @ 24-bit RGB)
                                      v
       +-------------------------------------------------------------+
       |                DDR2 视频帧缓存控制器 (读写握手)              |
       +-------------------------------------------------------------+
                                      | 96-bit (DDR 读出时钟域)
                                      v
======================== 工业视觉流水线 (本子系统) ========================
       |
       +---> [color_detect_96_v2] (4像素并行 Q10 YCbCr 色彩分割)
       |         |-- 帧内极值累加 (X/Y Bounds, Area)
       |         +-- 帧边界双缓冲稳态锁存 (O_xmin, O_xmax, O_ymin, O_ymax, O_area)
       |
       +---> [defect_classifier] (流式几何测量与缺陷判定)
       |         |-- 尺寸提取: W = xmax - xmin + 1, H = ymax - ymin + 1
       |         |-- 公差比较: W in [W0±ΔW] && H in [H0±ΔH]
       |         +-- 决策输出: PASS (绿) / NG (红) / NO_OBJECT
       |
       +---> [板级外设联动]
       |         |-- PASS: LED1 常亮, LED2 熄灭
       |         |-- NG:   LED2 常亮, LED1 熄灭
       |         +-- NO_OBJ: 双灯全灭
       |
       v (CDC 跨时钟域: 帧尾安全锁存至 HDMI 时钟域)
       +---> [bbox_draw_overlay] (HDMI 视频流 1 拍动态边框叠加)

                                      v
       +-------------------------------------------------------------+
       |                   HDMI Mixer / TMDS 编码输出                |
       +-------------------------------------------------------------+
                                      |
                                      v
       +-------------------------------------------------------------+
       |                   HDMI 720p@30fps 显示器                    |
       +-------------------------------------------------------------+
```

## 2. 96-bit 四像素接口与 Lane 映射规范

为匹配 DDR2 读写吞吐，图像数据在 DDR 读出端采用 96-bit 位宽传输，每拍包含 4 个连续的 RGB888 像素：

### 2.1 数据总线位域定义
- `I_tdata[95:72]`：Lane 0 像素（全局列号 $X = 4 \times x_{grp} + 0$），高位 $R[95:88]$，$G[87:80]$，$B[79:72]$
- `I_tdata[71:48]`：Lane 1 像素（全局列号 $X = 4 \times x_{grp} + 1$），高位 $R[71:64]$，$G[63:56]$，$B[55:48]$
- `I_tdata[47:24]`：Lane 2 像素（全局列号 $X = 4 \times x_{grp} + 2$），高位 $R[47:40]$，$G[39:32]$，$B[31:24]$
- `I_tdata[23:0]` ：Lane 3 像素（全局列号 $X = 4 \times x_{grp} + 3$），高位 $R[23:16]$，$G[15:8]$，$B[7:0]$

### 2.2 控制与同步语义
- `I_tvalid`：数据有效使能信号，仅在每行 320 个时钟周期内有效（$320 \times 4 = 1280\text{ px}$）。
- `I_tlast` ：行尾脉冲信号，在每行的第 319 拍使能，提示当前行扫描结束。
- `I_tuser` ：帧头起始脉冲，指示新一帧有效画面的第 1 个像素到达。
- 坐标计数器步进：$x_{grp} \in [0, 319]$，$y_{pos} \in [0, 719]$。

## 3. 稳态双缓冲锁存与抗抖动机制

### 3.1 既有代码缺陷与抖动根因
在原始参考实现中，包围盒极值 `xmin, xmax, ymin, ymax` 在帧头 `tuser` 时直接复位，随后在逐行扫描期间动态更新。如果下游 HDMI 显示模块直接读取这一组寄存器，HDMI 显示画面将在每一帧扫描过程中看到“从左上角拉伸放大到目标物体”的动态过程，在屏幕上表现为严重的**跳动、撕裂与残影**。

### 3.2 双缓冲架构设计
在 [`color_detect_96_v2.v`](file:///e:/Projects/FPGA-fallback/fallback/rtl/color_detect_96_v2.v) 中实施了严格的双缓冲隔离：
1. **活跃累加寄存器 (`acc_*`)**：在活跃视频期处理 4-Lane 流，独立累计当前帧的前景像素数与坐标极值。
2. **锁存输出寄存器 (`O_*`)**：仅在帧边界脉冲 `I_tuser` 触发的瞬间，当且仅当 `acc_area >= MIN_AREA` 时，将上一帧的稳态结果原子更新至输出端口；若面积不足则输出 `detected = 0`。
3. **稳态结果直供显示**：HDMI 画框器读取的是锁存输出寄存器，在整帧周期内值完全保持恒定，从而彻底实现**零抖动、零残影**的流畅边框绘制。

## 4. 20-bit 定点色彩空间转换与算术安全性

### 4.1 符号位扩展与溢出陷阱修复
RGB 到 YCbCr 的 Q10 定点矩阵运算：
$$\begin{aligned}
Cb &= \frac{512 \times B - 173 \times R - 339 \times G + 131072}{1024} \\
Cr &= \frac{512 \times R - 429 \times G - 83 \times B + 131072}{1024}
\end{aligned}$$

**关键缺陷排查**：
若将 8-bit 无符号变量 $R$ 直接声明为 `wire [7:0] R` 并进行 `$signed(R)` 强转，当 $R \ge 128$（例如典型红色工件 $R=150$）时，最高位为 1，Verilog 编译器将其解释为负数（$-106$），导致乘加结果彻底为负。同时，中间结果最大可达 $512 \times 255 + 131072 = 261632$，超过 18-bit 有符号整数的最大正值（$+131071$）。

**解决方案**：
统一使用零扩展 `20-bit` 有符号算术：
```verilog
wire signed [19:0] cb0 = 512*$signed({1'b0, B0}) - 173*$signed({1'b0, R0}) - 339*$signed({1'b0, G0}) + 20'sd131072;
wire signed [19:0] cr0 = 512*$signed({1'b0, R0}) - 429*$signed({1'b0, G0}) -  83*$signed({1'b0, B0}) + 20'sd131072;
wire [7:0] cb0_val = cb0[19] ? 8'd0 : cb0[17:10];
wire [7:0] cr0_val = cr0[19] ? 8'd0 : cr0[17:10];
```
位宽有充分裕量，绝对不发生算术溢出与正负翻转。

## 5. 尺寸测量、公差比较与缺陷判定

### 5.1 流式尺寸提取
- 像素宽度：$W = x_{\max} - x_{\min} + 1$
- 像素高度：$H = y_{\max} - y_{\min} + 1$
- 前景面积：$Area = \sum \text{Lane\_Hit}$

### 5.2 毫米标定公式（可选硬件映射）
在物距固定 $D$、焦距固定 $f$ 的工业台架上，毫米尺寸与像素尺寸具备线性比例：
$$S_{\text{mm}} = W_{\text{px}} \times K_{\text{calib}}$$
其中标定系数 $K_{\text{calib}}$ 可在 FPGA 中表示为 $Q8$ 或 $Q16$ 定点数（例如 $K = 0.50\text{ mm/px} \implies 128 / 256$）。在未完成实物台架标定前，系统遵循准则严谨输出像素尺寸，避免伪造未标定精度。

### 5.3 PASS/NG 缺陷判定状态机
在 [`defect_classifier.v`](file:///e:/Projects/FPGA-fallback/fallback/rtl/defect_classifier.v) 中：
- **PASS 条件**：`I_detected == 1` 且 $|W - W_0| \le \Delta W$ 且 $|H - H_0| \le \Delta H$。
- **NG 缺陷条件**：`I_detected == 1` 且（$|W - W_0| > \Delta W$ 或 $|H - H_0| > \Delta H$）。
- **NO_OBJECT 条件**：`I_detected == 0`（面积不足或未放置零件）。

外设输出真值表：
| 检测状态 | `O_pass` | `O_ng` | `O_no_obj` | LED1 (PASS) | LED2 (NG) | HDMI 边框颜色 |
|---|---|---|---|---|---|---|
| **合格品 (PASS)** | 1 | 0 | 0 | **亮** | 灭 | **绿色** (`24'h10b981`) |
| **超差品 (NG)**   | 0 | 1 | 0 | 灭 | **亮** | **红色** (`24'hef4444`) |
| **空场景 (NO_OBJ)**| 0 | 0 | 1 | 灭 | 灭 | **透明隐藏** (直通原图) |

## 6. HDMI 视频流动态画框器 (`bbox_draw_overlay`)

### 6.1 零 BRAM 占用流式结构
不同于需要整帧 Framebuffer 的复杂图形渲染卡，本项目利用显示时钟与坐标计数的实时同步性，采用仅 **1 级流水线寄存器** 实现动态边框替换：
```verilog
wire is_box_pixel = I_detected && (
  ((I_x >= I_xmin && I_x <= I_xmax) && (I_y >= I_ymin && I_y < I_ymin + LINE_THICKNESS)) || // 上边缘
  ((I_x >= I_xmin && I_x <= I_xmax) && (I_y > I_ymax - LINE_THICKNESS && I_y <= I_ymax)) || // 下边缘
  ((I_y >= I_ymin && I_y <= I_ymax) && (I_x >= I_xmin && I_x < I_xmin + LINE_THICKNESS)) || // 左边缘
  ((I_y >= I_ymin && I_y <= I_ymax) && (I_x > I_xmax - LINE_THICKNESS && I_x <= I_xmax))    // 右边缘
);

always @(posedge I_clk or negedge I_rst_n) begin
  if (!I_rst_n) begin
    O_de   <= 1'b0; O_hsync <= 1'b0; O_vsync <= 1'b0; O_rgb <= 24'd0;
  end else begin
    O_de    <= I_de;
    O_hsync <= I_hsync;
    O_vsync <= I_vsync;
    O_rgb   <= is_box_pixel ? (I_pass ? COLOR_PASS : COLOR_NG) : I_rgb;
  end
end
```
- **资源开销**：仅消耗 30~50 个 LUT 与数个 FF，BRAM 消耗为 **0**。
- **时序影响**：控制信号 (`de, hsync, vsync`) 严格同步推迟 1 拍，对视频输出时序完全透明。

## 9. 故障恢复与安全回退机制

1. **单按键硬直通模式**：板载按键保留原始视频模式切换，当处于直通模式时，HDMI Mixer 直接旁路工业视觉与边框逻辑，恢复最纯净的底层相机画面。
2. **空场景与目标丢失保护**：若流水线检测到连续 3 帧无有效目标，自动将 `O_detected` 置 0，强制清除边框并熄灭指示灯，防止屏幕残留失效线框。
3. **主分支隔离保护**：所有工业视觉开发均在 `fallback/industrial-inspection` 分支与对应 Worktree 执行，主分支 `main`（YOLO 预研）始终保持 100% 干净与完整。
