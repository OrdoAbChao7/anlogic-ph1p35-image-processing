# 题目二：基于安路 PH1P35 的实时数字图像处理系统

## 来源与页码

- 当前快照：`docs/research/snapshots/competition/topic2.pdf`，35 页；线上发布地址仍待核验。
- 封面（PDF 第 1 页）写 2026；题目二正文、基础/扩展/进阶要求和自备显示设备在 PDF 第 16–18 页。
- HX1P35A、SC520CS 适配背景及 `lab_ex_1/2/3` 描述在前面的平台章节第 6–8 页；该章节页眉仍写“2025”，资料包名称却为 `HX1P35A_Contest_202606`。引用时须写明页码和这处版本混排。

## 硬件和接口

- 推荐平台：安路 `HX1P35A`
- FPGA：`PH1P35MDG324`
 - 摄像头：本项目实际使用用户已购的 `SC520CS`；比赛平台章节的历史示例仅作为原始题目资料参考。SC520CS 的实物、连接和上板结果仍须核对。
- 摄像头接口：MIPI
- 输出接口：HDMI
- 显示器建议支持：`1280×720@60Hz`（第 18 页）；不是已实现的视频模式。

## 基本要求

1. 完成 MIPI 摄像头采集和 HDMI 实时显示。
2. 至少实现一种 FPGA 侧数字图像处理算法，例如灰度、二值化或边缘检测。
3. 处理后的视频稳定输出，连续运行无明显花屏、撕裂或中断。
4. 叠加图像或文字 OSD，包含安路 Logo。

## 官方示例对应关系

- `lab_ex_1`：MIPI 采集、DDR 缓存、HDMI 显示。
- `lab_ex_2`：边缘检测、DDR 缓存、HDMI 显示。
- `lab_ex_3`：MIPI、DDR、HDMI，并叠加 Logo 和运行计数。

## 建议验收路线

```text
Goal 1：原始摄像头画面稳定显示
Goal 3：灰度、二值化
Goal 4：Sobel 或其他实时算法
Goal 6：OSD 和应用判定
Goal 8：长时间运行和性能数据
```

## 使用边界

本文件只提取赛题约束。任何 PH1P35 的具体管脚、IP 配置和寄存器设置，都必须以实际开发板资料和官方工程为准。
平台章节第 6 页的 `38184` LUT 与题目正文第 16 页及安路产品页的 `38189` 不一致；冲突见 `../known-gaps.md`。
