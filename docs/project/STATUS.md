## 2026-10-20 V2 独立 worktree 失败快照

旧打包 V2 候选为 17,125 Route Slice、Setup WNS +104 ps；默认 inferred 的完整源码快照在 Placement 以 PHY-9053 失败，22,882 Slice、Gate WNS −7.560 ns；之后独立 R1 ERAM 完整路由候选为 19,749/21,216 Slice、Setup WNS/TNS −7,791/−307,321 ps、Hold +20/0 ps。三者输入与实现阶段不同，不拼接成同一版本；按用户批准的 90% Slice 预算，上限为 19,094，R1 仍超 655 Slice，且时序未收敛。既有实验中的 85% 是其当时预注册门槛，不追溯改写。精确身份与层级路径见 [G8 接管审计](../../work/g8_takeover_audit_20261020.md) 和 [V2 版本根因报告](../experiments/2026-10-20-v2-version-root-cause.md)。在单变量模块证据足以支撑资源与时序方向前，不启动新的完整 TD 构建。

## 2026-10-20 AWB early-token 隔离探针

精确 R1 源码的隔离候选通过定向 Icarus 回归及 25,231,360 组算术等价检查；一次匹配的模块 Gate 中 WNS −9.793→−0.994 ns、TNS −284.114→−16.696 ns，但仍未收敛，area `#slice*` +2、DSP 不变，且 TD 原始日志仍有未定位 wrapper 端口告警。该候选不晋级，未运行整机构建；完整输入、SHA、原始报告与退出门见 [实验记录](../../work/codex_awb_early_token_pipeline_20261020/EXPERIMENT.md)。R1 原始 Route 证据显示关键锥从 `fixed_mean` 的 Q32 `×1193047` 经 DSPMULT/DSPSIOU/DSPTADD、`fixed_average3` 的 `×683` 与 fanout-36 网络，再经过增益比较、步进/反馈算术到 `O_gain_r_reg[4]`；该 17.190 ns/16 级路径说明瓶颈是串接的帧级均值、目标均值和增益反馈计算，而非单个乘法器。下一包据此重新评估帧级 AWB 架构，不重复本探针，也不将模块 Gate 收益外推为整机收益。
