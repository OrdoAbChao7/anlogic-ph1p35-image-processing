# 采用固定红色零件传统视觉作为第一版主线

## 决策状态

- 状态：`APPROVED`
- 日期：2026-10-16
- 批准方式：用户在当前会话明确确认

## 背景

项目原固化目标同时包含主线智能视觉和备选工业视觉路线。YOLO/Micro-CNN 需要模型、INT8 权重、NMS、片上存储和视频链路资源，目前无法在既定时间和证据条件下形成可复现的单文件板级演示。工业视觉 Fallback 已完成软件 Stage D 等价模型回归，具备继续硬件化的确定性基础。

## 决策

第一版采用固定工位传统视觉，检测一种固定红色零件：

- 固定摄像头、物距、光照、背景和 ROI；
- 类别固定为 `red_part`；
- 目标总数固定输出 `0/1`；
- 使用 Q10 YCbCr 分割、3×3 开运算、面积、单目标 BBox、宽高和 PASS/NG 判定；
- 保留原图、Sobel、卡通化三种显示模式；
- 实现安路 Logo、模式、帧计数、检测框、类别、总数、尺寸和状态 OSD；
- 按键切换模式，LED 联动有效检测结果；
- 第一版不把 WM8978 语音作为通过门槛；
- 第一版不实现 YOLO/Micro-CNN、INT8 MAC、NMS、多类别和多目标检测；
- 现场运行交付目标为一个内嵌全部逻辑、Logo、字体和参数的 `.bit` 文件。

## 保留与不变

`docs/research/competition/topic2-requirements.md` 是比赛官方资料摘录，保留原文和来源，不因项目路线选择而改写。历史 YOLO 研究资料也保留，标记为本版本不采用。

## 影响

- `PROJECT_GOAL.md` 的主线从 YOLO/Micro-CNN 调整为固定红色零件工业视觉。
- `PHASES.md` 的 G5 改为固定红色零件检测，G6 不再以 WM8978 作为第一版验收条件。
- 验收矩阵改为单目标 `red_part`、`0/1` 和固定工位场景。
- 后续实现必须先完成 G1/G2 视频和接口闭环，再把 Fallback 模块接入统一顶层。
- 不得把软件 Stage D 或独立 TD 构建写成整机上板通过。
