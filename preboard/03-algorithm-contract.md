| 功能 | 候选定义 | 输出范围 / 边界 |
| --- | --- | --- |
| 二值化 | `pixel >= threshold` 输出 255，否则 0 | threshold 为 0–255；逐像素处理 |
| Sobel | 标准 `3×3` Gx、Gy；幅值近似 `min(255, abs(Gx)+abs(Gy))` | 外圈边界输出 0；不做隐式卷积填充 |
| 边缘二值化 | Sobel 幅值 `>= edge_threshold` 输出 255，否则 0 | threshold 为 0–255 |
| 目标面积 | 当前模型统计整幅图中值为 255 的像素数；ROI 尚未实现 | 无目标为 0 |
| BBox | 目标像素坐标的最小/最大值，端点均包含 | 无目标为 `null`；宽高分别为 `xmax-xmin+1`、`ymax-ymin+1` |

## 尚需冻结的决策

- RGB → 灰度的通道顺序、系数、舍入和饱和策略：待确定。不得在 RAW/Bayer 尚未确认时假定 RGB 输入。
- 卡通化的颜色量化级数、区域填充规则，以及 YOLO-tiny 的输入尺寸、INT8 量化比例/零点、裁剪层、NMS 阈值和类别表：待模型与资源预算确认。加入参数时必须同步修改软件模型、测试向量、权重/ROM 和 RTL。
- Sobel 是否输出灰度幅值或阈值化边缘，以及模式切换时机：待接口和 UI 决策。
- 流式 `3×3` 窗口的行首、帧首和背压行为：需在 RTL 实现时与本模型逐项对应。
